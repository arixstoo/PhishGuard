Vérifier un message ou un lien

Collez un SMS, un message ou un lien qui vous paraît douteux : PhishGuard vous dit s'il ressemble à du phishing, et pourquoi.

🔒 Ne collez pas de mot de passe ou de données personnelles. Le texte est envoyé à ce serveur pour être analysé, puis oublié.

PhishGuard ne visite jamais les liens : il les analyse comme du texte. Un verdict « sûr » n'est pas une garantie ; en cas de doute, contactez l'organisme par ses coordonnées officielles.
